This utility loads an image into a WebUI and sends it to a localhost server initiated from PowerShell. This interfaces with the official unmodified LightScribe System Software, allowing LightScribe drives to be used on Windows 10/11.
This software was created entirely by Claude and I do not own it nor pretend to understand how it works. It was for a personal project and I do not intend further development, but I do not want to gatekeep the tool produced here either.
Feel free to use or modify this.
